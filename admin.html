바뀐 내용

    GitHub에 올리는 방법 (1분)

    1. GitHub 저장소에 로그인한 상태로 들어갑니다.
    2. 오른쪽 위 Add file → Upload files를 누릅니다.
    3. 방금 내려받은 파일(index.html)을 끌어다 놓습니다. 같은 이름의 파일이 새 것으로 바뀝니다.
    4. 아래 Commit changes 버튼을 누릅니다.
    5. 1~5분 뒤 학생 앱 주소에서 바뀐 내용이 보입니다. 홈 화면에 설치한 앱은 한 번 껐다 켜면 새 내용이 나옵니다.

    ※ 파일 이름을 바꾸지 마세요. 다운로드 폴더에 같은 이름이 있으면 index (1).html처럼 저장될 수 있으니, 올리기 전에 index.html로 이름을 맞춰 주세요.
